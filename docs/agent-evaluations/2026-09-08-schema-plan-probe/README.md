# Model × reasoning effort：Schema 计划设计探索

日期：2026-09-08。这是工作方法实验，不是产品施工分片，不改变 DurableGraph 设计。

问题：能否构造一道主力配置 `gpt-6-astra @ xhigh` 满分、`gpt-5.6-sol @ medium` 漏掉关键点的自包含设计题？这是待检验假设，允许两者都通过、都失败或顺序相反。

## 材料与协议

- [题目 v1](problem-v1.md)：唯一答题材料。
- [评分标准 v1](rubric-v1.md)：答题前冻结，不提供给答题 agent。
- 每次 `fork_turns: none`；指定上述模型和 effort；相同提示模板，仅输出路径不同。
- 禁止读取其他仓库文件、记忆、Git、评分表和其他候选答案；禁止网络与进一步委派。工具只用于读题和写答案。
- 这依赖 agent 遵守读写边界，共享工作区不是安全隔离环境。检查可见工具操作，违规样本标记污染。
- 初轮每配置一份；若出现目标差异，以同一冻结题目再各跑一份检查是否复现。若初轮无差异，先诊断题目，不悄悄修改评分或只挑有利结果。
- 随机标签用于答案文件和评分；编排者知道配置，因此其评分不算盲评。可另派只读题目、rubric、匿名答案的独立评审。
- 记录请求配置与工具返回的身份；若宿主未提供独立实际模型/effort 确认，不声称核实了底层运行配置。
- 不让答题者自行估计内部用量；不可获得的 usage 标为 unavailable。等待时间仅作粗略运行时间，不换算订阅额度。
- 不收集隐藏思维链，只保留最终方案与简短工程论证。无需产品 build/test；文档校验检查输出、链接和 diff。

## 本轮结果

**未达到目标区分：首轮两份答案均为 20/20，均未发现关键语义错误。** 编排者评分与不知配置映射的独立评审一致；评分是设计审查，不是完整实现的可执行验收。

| 请求配置 | 原始答案 | 编排者 / 匿名评审 | 派发至答案落盘的粗略时间 |
|---|---|---|---|
| gpt-6-astra / xhigh | [sample-kestrel](sample-kestrel.md) | 20/20 · 20/20 | 约 5 分 21 秒 |
| gpt-5.6-sol / medium | [sample-orchid](sample-orchid.md) | 20/20 · 20/20 | 约 3 分 15 秒 |

两者均发现深层同 Key 冲突、共享 DAG 长路径、缓存后晚登记冲突和回调后类型检查的问题。两者都处理了一个没有直接列成要求的边界：Authority 的已登记根可能带有无法独立查询的子声明，因此需比较返回 Node 的实际完整闭包。

Astra 用全部物理节点的局部签名一致性加归纳证明解决完整布局相等；Sol 用精确 hash-consing 构造规范 Shape。前者引入的概念较少，并进一步列明根数/字段扫描成本；后者也正确，冻结 rubric 不要求某个特定实现，不能事后把该差异改成失分。

时间是共享宿主下的派发窗口到文件修改时间，含工具往返；不是纯推理耗时。工具没有提供独立实际配置或 usage 遥测，无法据此推算订阅额度、内部推理长度或稳定速度比。匿名评审继承编排环境的默认模型/effort，未另作 override；它未获得配置映射，仍是模型评审而非人工证明。

## 证据与限制

- [冻结题目](problem-v1.md)、[事前 rubric](rubric-v1.md)、[请求配置与文件 hashes](manifest.json)。
- [编排者逐项评分](coordinator-review-v1.md)、[独立匿名评审](blind-review-v1.md)。
- [四个可执行反例检查](sanity-checks.md)：确认题目中两个核心缺陷和合法边界，不冒充候选方案的完整实现验证。
- 两个答题 agent 的最终消息只交付文件路径；未索取隐藏推理或会话记录。没有额外读取答题会话来审计全部工具访问，因此共享目录防污染依赖协作约束，不能声称已证明完全隔离。
- 题目、rubric 的 SHA256 在运行前后相同，两个原始答案不作编辑；只完成一对探索样本，不声称模型等价或得分已稳定。

## 下一次如何改进实验

这道题逐项暴露了风险并给出错误伪代码，主要测“根据明确线索修复设计”。它没有测到从稀疏产品请求中独立发现跨阶段约束的能力。若继续，优先另写合同明确但减少解法提示的新题，重新冻结评分，对两配置一视同仁；保留本轮双满分结果。

当前暂停于首轮结论，没有为了得到预期排序而改分或反复抽样。本实验不改变产品进展或默认模型/effort 选择规则。
