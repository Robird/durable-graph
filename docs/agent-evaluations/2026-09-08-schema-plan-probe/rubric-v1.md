# 评分标准 v1（不提供给答题 agent）

在首轮答题前冻结。10 项各 0/1/2 分，共 20 分。2 分要求有明确、可检查的算法或反例；仅笼统提到原则给 1 分；缺失或实际算法违反给 0 分。相同语义的不同算法同样得分，不要求复现 DurableGraph 的当前实现。严重错误单独标记，不能用其他小点抵消。

| ID | 满分条件 | 关键项 |
|---|---|---|
| R1 | 区分物理 Node、完整 Key（含泛型实参）、完整布局、CLR DTO Type；不以 Key 或 DTO 类型代替布局相等 | 是 |
| R2 | 给出局部签名相等但深层不等的同 Key 双声明反例，并修复早退：处理全部不同物理声明，或者等效的完整结构认证；不能仅保存第一个 Key 后忽略其余子图 | 是 |
| R3 | 给出共享子树首次浅路径、后来深路径导致内部越界的反例；采用 DAG height + 到达深度、拓扑最长路径或等效方案，不依赖首次 visited 深度 | 是 |
| R4 | 每次 Execute 重新核对当前 Authority；缺项可接受、晚登记冲突拒绝；不复用永久 HasValidated、不自动登记、不静默重绑定 | 是 |
| R5 | Authority 比较完整布局，且讲清跨图比较实现与成本；例如将两个自洽且闭合的图按 Key 局部签名对照全部条目，或共享 memo 的结构认证。不能仅比较 registered.Key，也不能无说明地声称反复深比较为 O(K) | 是 |
| R6 | 收集全部 owner 步骤端点与零步 owner；解释声明值工具即使未使用也已被端点 exact 闭包覆盖；不递归 nominal Ref | 否 |
| R7 | Schema 校验及最终 CLR T 精确匹配均在所有 callback 前完成；最终 Type 来自缓存计划；不以最后 cast 检查替代 | 是 |
| R8 | 同 Key 异形记录可重现的两个来源路径；权威冲突给 Plan 路径；保留稳定遍历/错误选择，不能依赖哈希枚举随机次序 | 否 |
| R9 | 预处理按物理 DAG 共享，明确 O(N+E) 或合理的额外成本；运行期按逻辑 Key 去重查 Authority；不展开指数条路径，不为此新增独立值依赖登记系统/generation/并发协议 | 否 |
| R10 | 至少四个针对性测试，覆盖深层同 Key 冲突、共享深度路径、缓存后晚登记、callback 前失败中的至少四种具体失效场景；断言能真正区分错误实现 | 否 |

## 审题参考与反例

### 同 Key 物理双声明

两个 Root 字段分别引用 `A1`/`A2`（共同 Key A），各自 inline `B1`/`B2`（共同 Key B）。B1 的字段是 Scalar(I32)，B2 为 Scalar(I64)。A1/A2 的 LocalSignature 完全一致，按 Key 早退漏掉 B 的冲突。正确算法可按物理地址 visited，逐个访问不同物理声明，再按 Key 比较局部签名；如果每个可达声明都已检查，递归一致性随 DAG 归纳成立。

### 后到深路径

L=4；R.field[1] -> S -> T，深度为 1,2,3；R.field[2] -> A -> B -> S -> T，深度为 1,2,3,4,5。草案第二次到 S 的 depth=4 合法，随后按 Key 返回，漏掉 T 的 depth=5。最简单的线性证明是物理 DAG 自底向上计算 height(node)=1+max(height(child))，每个根 height<=L；亦可在稳定 DFS 遇共享节点时检查 depth+height-1。报告深度错误可沿最大 height 的稳定子边构造一个见证路径，无须打印全部路径。

### 权威比较

若两边都经过完整闭包自洽认证，且每个登记条目的所有依赖都可按 Key 查到，那么逐 Key 比较 LocalSignature 足够：父边 key 保持，子要求也在列表内被比较。若 Authority 的闭包认证不等于可逐 Key 检索所有子条目（题目没有显式承诺后者），必须实际遍历被查到的权威 Node 闭包/认证其完整布局，或明确补足接口所需条件，不能偷偷假定子 key 都可查到。此点计入 R5。

可以在每次 Execute 为 registered physical nodes 做去重闭包签名比较，利用 Plan 的要求表逐一核对，从而成本为 O(K+Nr+Er)，Nr/Er 是本次命中登记 Node 的不同物理闭包。精确结构 canonical fingerprint 也可以，但哈希只能作索引，不能不处理碰撞而代替严格相等。题目允许执行期扫描 K，并没有保证外部权威图读取或结构比较为 O(K)；诚实报告成本可满分。

### 评分与实验边界

- 不根据哪个模型回答来调评分；先按随机标签评审。
- 如果题目有歧义，登记问题和受影响分项；不能看完结果后改 rubric 使某配置输。修订必须另立 v2，对两边都重新运行。
- 此题有意组合已知难点，是探索区分度的样本，不是代表性基准。一个满分和一个失分只表明这两个产物不同。
- 不索取、保存或分析隐藏思维链；只评分最终方案、作者主动给出的简短论证与测试设计。
